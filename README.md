# FTTH/GPON Fault Diagnostics & Field Operations

This repository contains a technical portfolio project simulating field operations for an FTTH/GPON network. It demonstrates structured troubleshooting, incident management, and SLA tracking.

### 📊 Project Deliverables
*   **Network Topology & Fault Domains:** Visualizing the GPON architecture from OLT to Customer Premises.
*   **Fault-Isolation Flowchart:** A standard operating procedure for diagnosing LOS alarms, provisioning failures, and Wi-Fi interference.
*   **KPI Dashboard:** An Excel-based incident log tracking Mean Time to Restore (MTTR), SLA compliance, and fault distributions.
*   **Technical Report:** A comprehensive write-up of the methodology and operational improvements.

### 🛠️ Tools Used
Diagrams.net (Network Layout) | Excel (KPI Tracking) | Markdown (Documentation)
